# Security Policy

Living World is a RimWorld mod, so "security" here mostly means changes that could
corrupt a player's save, crash the game, or cause data loss through the world ledger
or its Harmony patches. Reports about any such issue are welcome.

## Supported versions

Only the latest `main` is actively maintained. Fixes are applied there; there are no
long-term support branches yet.

## Reporting a vulnerability

Please do **not** open a public issue for a security-sensitive report.

- Preferred: use GitHub's private **"Report a vulnerability"** flow
  (repository **Security → Advisories → Report a vulnerability**).
- Alternatively, email **timeshift92@outlook.com** with:
  - a description of the problem and its impact (crash, save corruption, data loss, etc.);
  - steps to reproduce, ideally with a minimal mod list;
  - the RimWorld version and Living World commit/version affected.

Please give a reasonable window to investigate and ship a fix before any public
disclosure. You will be credited in the fix unless you prefer to remain anonymous.
