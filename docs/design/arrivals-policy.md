# Living World — Политика прибытий (Sys 1): ничего «из ниоткуда»

Статус: **аудит + дизайн, к согласованию.** Отвечает на прямую цель проекта:
**мир должен быть предсказуем — у каждого появления людей/караванов/угроз обязан
быть контролируемый источник или честное происхождение.** Сейчас половина мира
живая (рейды travel'ят, мехи из кластера, дрифтеры из резервуара), а вторая
половина сыплется ванильным рандомом (караван-встреча, странник, беженец).

Связано: [storyteller-normalization.md](storyteller-normalization.md) —
**механизм уже спроектирован** (свой `IncidentDef`+worker, gated ledger'ом;
приглушение ванили; identity-comp). Этот док **не дублирует механизм**, а
применяет его **ко всему классу прибытий** по результатам аудита. Также:
[world_ownership.md](../world_ownership.md), [vision.md](../vision.md)
(правило «nothing appears from nowhere»), [simulation.md](../simulation.md).

---

## 1. Принцип: 4 корзины для любого прибытия

Цель не «убрать рандом», а **«у каждого прибытия — контролируемый источник ИЛИ
честное происхождение»**. Каждый ванильный инцидент-прибытие попадает в одну из 4:

| Корзина | Что делаем | Пример |
|---|---|---|
| **A. Честное происхождение** | Оставляем как есть — у него уже есть believable-источник (орбита, подземка, погода) | падение корабля, орбит-торговец, инсекты, погода |
| **B. Сорсить из ledger** | Перехват → своё событие, где сущность = реальный NPC из реального поселения, **пришедший** (как рейды/мехи) | торговый караван, визит-группа, союзная помощь |
| **C. Подавить** | Не сорсится и не критично геймплейно → режем частоту/вырубаем | одинокий враг «из воздуха» |
| **D. Пере-фреймить** | Не сорсится, но нужно → правдоподобный повод вместо телепорта | одинокий присоединяющийся странник = из дрифтер-резервуара |

Механизм для B/C/D — **уже готов** (normalization §4): свой `IncidentDef` в
ванильной категории, gated `CanFireNowSub` по ledger'у, ваниль приглушаем XML-patch'ем
веса; identity-comp вешаем на материализации.

`FarmAnimalsWanderIn`, `HerdMigration`, `SelfTame`, `ThrumboPasses` — животные должны
**вычитаться из локальных диких когорт** (`WorldAnimalCohort` уже есть!), а не спавниться
из воздуха. Манхантер-пак = реальное сокращение когорты биома.

### C — ПОДАВИТЬ/пере-фреймить (одиночки без источника)
Ванильный «одинокий враг из ниоткуда» (часть `PawnsArrive`/ambush-путей без фракц-каравана):
режем частоту или пере-фреймим («вышел из глуши»), а не телепорт-и-атака.

`GiveQuest`, `GiveQuest_Map` (квесты — свой фрейминг), `GameEndedWanderersJoin` (эндгейм),
`Ambush` (база).

## 3. Единая механика (переиспользуем normalization, не изобретаем)

Для каждого B/D-инцидента — **один паттерн** (уже обкатан на рейдах/дрифтерах):

1. **Свой `IncidentDef`** в той же ванильной категории (Misc/FactionArrival/ThreatBig).
   Ванильный сторителлер сам его планирует; частота — вес + `CanFireNowSub`-гейт.
2. **`CanFireNowSub`** = «есть ли чем наполнить из ledger?» (поселение-источник,
   дрифтер в резервуаре, когорта животных). Нет источника → не стреляет.
3. **`TryExecuteWorker`** = материализация из ledger + `CompLivingWorldIdentity`.
   Где уместно — **travel-маркер на карте мира** (переиспуем `WorldObject_LivingWorldArmy`),
   чтобы игрок видел приближение (как travel-рейды).
4. **Приглушение ванили** — XML `PatchOperation` на вес ванильного инцидента (данные,
   не код; откатываемо). Вырубаем совсем только «одиночек ниоткуда» (корзина C).
5. **Fail-open:** нет источника / ошибка → ванильный инцидент отрабатывает как был
   (ничего не теряем).

Ключ: это **аддитивно и совместимо** (Rim War, чужие мод-патчи) — мы не воюем за
ванильные методы генерации, а кладём свой контент в пул и глушим ванильный весом.

## 4. Порядок срезов (по частоте × felt-эффекту)

1. **Торговые/визит/путник-группы** (`TraderCaravanArrival`, `VisitorGroup`,
   `TravelerGroup`) — самое частое «группа появилась». Сорсить из реального поселения
   + travel-маркер. Огромный felt-выигрыш, переиспользует маркер + материализацию визитёров.
2. **Одиночки-присоединяющиеся** (`WandererJoin`, `WildManWandersIn`) — из
   дрифтер-резервуара (уже есть) → «пришёл из потока», не из воздуха.
3. **Караван-встречи в пути** (`CaravanMeeting`, `Ambush_EnemyFaction`, `CaravanDemand`) —
   привязать к ledger-каравану/армии, реально идущему рядом с караваном игрока. Это тот
   самый кейс Dezaight.
4. **Союзная помощь** (`RaidFriendly`) — из реального союзного поселения.
5. **Животные из когорт** (манхантеры/миграции) — вычитать из диких когорт биома.
6. **Дань/выкуп** (`TributeCollector`, `RansomDemand`) — из имперского/держащего поселения.

Каждый срез самодостаточен, TDD-покрыт, ваниль приглушается только для сделанного.

## 5. Открытые вопросы

- **Приглушение ванили: XML-вес vs `CanFireNowSub`-гейт?** (normalization §9) — по
  каждому инциденту замерить, хватает ли данных-патча.
- **Караван-встречи в пути:** нужен ли ledger-караван физически рядом с караваном
  игрока по гео, или достаточно «есть активный караван этой фракции в регионе»?
- **Животные:** вычитать из когорт строго (конс-safe) или мягко (когорта как «мягкий
  потолок»)? Влияет на то, могут ли манхантеры прийти при пустой когорте.
- **Порог подавления одиночек (C):** резать полностью или оставлять редко «из глуши»?
- **DLC Anomaly:** точно оставляем весь трек, или монолит-угрозы тоже хотим «с поводом»
  (богатство/провокация, как мехи)? — вероятно отдельный будущий трек.

## 6. Статус реализации (закрытие)

Финальная диспозиция по каждому пункту корзины B и «мелочи». Проблема «из ниоткуда»
для наземных людских прибытий — **закрыта**.

| Пункт | Итог |
|---|---|
| `RaidEnemy` (humanlike) | ✅ travel-рейды (`LivingWorld_FactionRaid`) |
| `RaidEnemy` (mech) | ✅ мех-кластеры-источники на карте |
| `VisitorGroup` / `TraderCaravanArrival` / `TravelerGroup` | ✅ travel из поселения (срез 1, `ApproachingGroup`) |
| `CaravanArrivalTributeCollector` | ✅ **авто-покрыт** — наследует пропатченный `TraderCaravanArrival.TryExecuteWorker` |
| `WandererJoin` | ✅ сорсится/гейтится дрифтер-резервуаром (срез 2) |
| `CaravanMeeting` / `Ambush_EnemyFaction` / `CaravanDemand` | ✅ гейт «рядом с поселением» (срез 3, общий `LivingWorldCaravanEncounterGate`) |
| `WildManWandersIn` | ⬜ **оставлен** — феральный из дикой природы = честное происхождение (корзина A) |
| животные (манхантер/миграция) | ⬜ **оставлен** — локальный биом = честное происхождение; ledger-когорты (per-NPC-поселение) к player-local живности не мапятся |
| `RansomDemand` | ⬜ **оставлен** — это сообщение (выкуп пленника), не спавн |
| `RaidFriendly` | ⬜ **оставлен** — союзная помощь: позитивная и срочная (travel опоздал бы); почти всегда из фракции с поселением |
| орбита / погода / флора / подземка / DLC Anomaly | ⬜ честное происхождение — не трогаем |

**Вывод:** каждое наземное людское/караванное прибытие теперь либо приходит из
реального ledger-источника (видимо travel'ит), либо гейтится «рядом с источником»,
либо сорсится из отслеживаемого пула. Остаток имеет честное происхождение
(дикая природа, орбита, аномалия) или является сообщением, а не появлением из
пустоты. Sys 1 достигнута для своей цели: мир предсказуем, у каждого прибытия виден
источник.

Следующие (не про «из ниоткуда», отдельные треки): DLC-Anomaly-угрозы «с поводом»,
опциональный сторителлер (Phase 8), уничтожение мех-кластера как felt-цель.
